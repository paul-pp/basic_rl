# Reinforcement Learning Notebooks

This project contains two reinforcement learning examples implemented with Gymnasium:

- **FrozenLake** — trains and evaluates an agent using tabular Q-learning.
- **LunarLander** — trains and evaluates an agent using Deep Q-learning (DQN) with experience replay and a target network.

Both notebooks demonstrate the environment with a random policy, train an agent, plot training metrics, and run the trained agent for evaluation.

## Requirements

- Python **3.11.13**
- The packages listed in `requirements.txt`

## Installation

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Create and activate a virtual environment:
   On macOS or Linux:

   ```bash
   source .venv/bin/activate
   ```

4. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

## Solution
